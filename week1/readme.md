Titanic Data Analysis

Project Overview

This is a beginner-level data analysis project using the Titanic dataset.



The main purpose of this project is to understand the dataset, clean the data, perform basic data preprocessing, and visualize important patterns in the data.

Tasks Performed

Imported the Titanic dataset

Explored the dataset

Checked for missing values

Handled missing values

Performed data cleaning

Encoded categorical data where required

Created data visualizations

Exported the cleaned dataset

Technologies Used

Python

NumPy

Matplotlib

Jupyter Notebook

Conclusion

This project helped me understand the basic workflow of a data analysis project, from importing and cleaning raw data to visualizing the cleaned data and exporting the final dataset.
